macOS • Apple Silicon. This build is ad-hoc signed and not notarized. If macOS blocks the first open, right-click the app, choose Open, then Open again.

Unofficial Apple TV remote: it talks to Apple TV over reverse-engineered protocols (not an Apple API), so it can break on a tvOS update. Note: live PIN pairing is not wired up yet in this build — the app discovers and shows an Apple TV by name, but does not yet prompt for the 4-digit PIN or open a live session, so it will not drive a TV yet.
